# Landing page draft

Static, dependency-free draft for the CodeRoamer marketing site.

Serve only the landing directory:

```bash
python3 -m http.server 8080 --directory landing
```

Then open:

```text
http://localhost:8080/
```

The draft is intentionally separate from the Expo web application. It can later be moved into a
dedicated site project or translated into React components once the positioning and visual
direction are approved.
